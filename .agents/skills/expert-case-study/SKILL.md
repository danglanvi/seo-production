# Expert Case Study Writing

Write short-form (150-400 words), professional SEO case studies that demonstrate expertise and methodology.

## Core Structure

```
1. HEADLINE - [Industry] + [Context/Differentiator]
2. METADATA - Industry, Language, Timeline (optional)
3. METRICS - 4-6 results with before/after numbers
4. DIFFERENTIATION - "What makes this different is..."
5. METHODOLOGY - Named method + specific implementation
6. FRAMEWORK - 4 principles (always 4 items)
7. INSIGHT - "Why this worked" explanation
8. CLOSING - One-liner with contrast pattern
```

## Style Rules

**DO:**
- Results-first, methodology-focused
- Named methodologies ("Link Sprints", "Function First")
- Technical vocabulary (semantic architecture, frame semantics)
- Short, declarative sentences
- 4-item principle lists
- Closing one-liner: "This is not X. This is Y."

**DON'T:**
- Personal narrative ("team mình", struggles, journey)
- Timeline storytelling
- Emotional language
- Hedging words (may, might, could)
- Excessive explanations

## Quick Reference

### Metrics Format Options

**Format A: % change with absolute numbers**
```
📊 +185.78% clicks, 9.44K → 27K
📊 +89.97% impressions, 353K → 671K
```

**Format B: Before → After with % in parentheses**
```
• Total Clicks: 24.4K → +255.63% (from 6.86K)
• Average Position: 6.4 → ↑ 16.88% (from 7.7)
```

**Format C: Simple percentage**
```
• 24% increase in clicks
• 51% improvement in average position
```

### Differentiation Patterns

- "What makes this case study different is that [unique factor]."
- "This is a rare case where [unusual approach]."
- "This flips the traditional [assumption] mindset."
- "The impact came almost entirely from [specific method], not [common assumption]."

### Framework Pattern (Always 4 Items)

```
Our methodology consistently applies four principles:
• [Principle 1]
• [Principle 2]
• [Principle 3]
• [Principle 4]
```

### Closing One-Liner Pattern

```
This is not [common assumption]. This is [actual methodology].
```

Examples:
- "This is not content volume. This is semantic architecture."
- "Experience amplifies function."

## Google's Self-Assessment Questions

From Google's official guidelines, audit against:

### Content and Quality
- [ ] Provides original information, reporting, research, or analysis
- [ ] Provides substantial, complete topic description
- [ ] Provides insightful analysis beyond the obvious
- [ ] If drawing on sources, adds substantial value (not just rewriting)
- [ ] Heading/title provides descriptive, helpful summary
- [ ] Content you'd want to bookmark, share, or recommend
- [ ] Would expect in printed magazine, encyclopedia, or book
- [ ] Provides substantial value vs other search results
- [ ] No spelling or stylistic issues
- [ ] Produced well (not sloppy or hastily produced)
- [ ] Not mass-produced or outsourced

### Expertise Questions
- [ ] Presents information that builds trust (clear sourcing, expertise evidence)
- [ ] Site is well-trusted or authoritative on topic
- [ ] Written/reviewed by someone who demonstrably knows the topic
- [ ] No easily-verified factual errors

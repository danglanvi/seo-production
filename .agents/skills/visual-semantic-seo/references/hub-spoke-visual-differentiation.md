**When to use:** Site has hub-spoke architecture (homepage hub + category/detail spokes). Need to differentiate visual treatment between hub and spoke pages so Google + user identify each page's role correctly.

**Core principle:** Same brand, same template foundation, but **distinct visual signal intensity** between hub and spoke. Hub = dominant visual presence. Spoke = focused visual presence.

---

## The Foundation Problem

When site has multiple pages using similar templates (homepage + category pages + detail pages), risk arises:

1. **Visual similarity hides hierarchy** — user can't tell which page is "main" vs "drill-down"
2. **Google fails to identify hub** — without distinct visual signals, hub authority diluted
3. **User confusion on funnel position** — homepage feels same as category, conversion drops

**Solution:** Apply visual signal intensity differentiation between hub and spoke.

---

## The 7-Element Visual Differentiation Matrix

Every hub vs spoke pair should differ across these 7 elements:

| Element | Hub Visual Signal | Spoke Visual Signal |
|---|---|---|
| **1. Hero size** | Full-width 1920×800 dominant | Reduced 1920×600 |
| **2. Above-fold CTA count** | 3-4 buttons (multi-path) | 1-2 buttons (focused) |
| **3. Trust strip layer count** | 7 layers full stack | 4-5 essential layers |
| **4. Centerpiece count** | 2-3 layers | 1 layer |
| **5. Templated repetition** | 4+ entities (e.g., 4 product lines) | 1 entity deep |
| **6. FAQ encyclopedia** | 4 tabs × 4-5 questions | 1-2 tabs × 3-5 questions |
| **7. Visual divider style** | Strong section breaks (color blocks) | Subtle dividers (border lines) |

---

## Element 1 — Hero Size Differentiation

### Hub Hero
- Dimensions: 1920×800 desktop (full attention grabber)
- Mobile: 100vh on first scroll
- Background: Full bleed image OR video
- Text overlay: H1 large (48-64px) + L0 paragraph + 4-6 trust attributes + multi-CTA

### Spoke Hero
- Dimensions: 1920×600 desktop (40% smaller than hub)
- Mobile: 70vh on first scroll
- Background: Solid color OR muted image
- Text overlay: H1 medium (36-48px) + L0 paragraph + 1-2 trust attributes + single CTA

**Why:** Hub hero must dominate to establish brand authority. Spoke hero needs to be efficient — user already past awareness, wants to act.

---

## Element 2 — Above-Fold CTA Count

### Hub CTA Pattern
```
[Primary CTA]    [Secondary CTA]    [Tertiary CTA]
"Get Started"    "Talk to Sales"    "View Demo"
```

3-4 CTAs cover multiple buyer journey paths (free trial / sales / education / demo).

### Spoke CTA Pattern
```
[Single Strong CTA]    [Optional Soft Link]
"Buy Now"              "Learn More →"
```

1-2 CTAs — user reached this page with specific intent, drive that intent forward.

**Anti-pattern:** Spoke with 4+ CTAs creates choice paralysis at decision stage.

---

## Element 3 — Trust Strip Layer Count

### Hub: Full 7-Layer Trust Stack
1. Search engine reviews badge (above-fold)
2. Press logos (boilerplate-adjacent)
3. Video reviews with name + role
4. Multi-platform review badges (G2, ProductHunt, etc.)
5. Verified customer reviews
6. Live stats bar
7. Team member profiles

### Spoke: 4-5 Essential Layers
1. Search engine reviews badge (above-fold) — ESSENTIAL
2. Press logos — OPTIONAL (could skip for product-specific page)
3. Video reviews — ESSENTIAL but reduce count (2-3 vs 4-6)
4. Multi-platform badges — OPTIONAL
5. Verified customer reviews — ESSENTIAL but product-specific
6. Live stats bar — OPTIONAL
7. Team profiles — SKIP (link to hub)

**Rule:** Spoke trust layers must be **product/category-specific** when present, not generic. Spoke that copies hub's generic trust signals = wasted real estate.

---

## Element 4 — Centerpiece Count

### Hub: 2-3 Centerpiece Layers
- L1: Discovery centerpiece (Above-fold)
- L2: Conversion centerpiece (Mid-page pricing comparison)
- L3 (optional): Per-entity templated centerpieces

### Spoke: 1 Centerpiece Layer
- L1 only: Focused on the spoke's specific intent

**Why:** Multiple centerpieces work for hub because it serves multiple intents. Spoke serves 1 intent — additional centerpieces dilute focus.

---

## Element 5 — Templated Repetition Count

### Hub Pattern
4+ entity sections templated:
- Hub for SMM panel: Instagram + TikTok + YouTube + Facebook (4 platforms)
- Hub for hair manufacturer: Tape-In + Weft + Closures + Frontals (4 product lines)
- Hub for course platform: 8-10 modules templated

Each entity = 1 templated section identical structure.

### Spoke Pattern
1 entity deep:
- Spoke `/buy-instagram-followers`: ALL content focused on Instagram followers (not other platforms)
- Spoke `/raw-vietnamese-hair`: ALL content focused on raw type (not virgin/remy)

Templated repetition INSIDE spoke = sub-variations only:
- Spoke for Instagram followers: 1K, 5K, 10K, 50K, 100K, 500K tiers (6 volume tiers)
- Spoke for raw hair: 8", 12", 16", 20", 24" lengths (5 length variants)

---

## Element 6 — FAQ Encyclopedia Size

### Hub FAQ
- 4 tabs (e.g., Safety / Choose / Growth / Future)
- 4-5 H2 questions per tab = ~16-20 total questions
- Cover full search journey (TOFU + MOFU + BOFU)

### Spoke FAQ
- 1-2 tabs OR no tabs (flat list)
- 3-5 H2 questions per tab = ~5-10 total questions
- Cover product-specific concerns only

**Rule:** Spoke FAQ doesn't need to cover concerns about other products. Link to hub FAQ for broader questions.

---

## Element 7 — Visual Divider Style

### Hub Visual Dividers
- Full-width color blocks alternating sections
- Background gradient transitions
- Strong section breaks with icons/numbers
- Padding 80-120px between major zones

### Spoke Visual Dividers
- Subtle horizontal border lines
- Whitespace-based separation
- Minimal section break ornamentation
- Padding 48-64px between major zones

**Why:** Hub needs visual variety to keep user engaged through long page (5000+ words). Spoke is shorter (1500-3000 words), excessive ornamentation feels heavy.

## Page-Tier Visual Spec Summary

```
TIER 1 — HUB (Homepage / Primary Landing)
├─ Hero: 1920×800 dominant, 4 CTAs, multi-trust
├─ 7-layer trust stack full
├─ 2-3 centerpiece layers
├─ 4+ entity templated sections
├─ 4-tab FAQ × 4-5 Q each
├─ Strong color block dividers
└─ Word count: 5000-10000+

TIER 2 — CATEGORY (Product Family / Service Hub)
├─ Hero: 1920×700, 2 CTAs
├─ 5-layer trust stack
├─ 1-2 centerpiece layers
├─ 1 entity, 5-7 sub-variations
├─ 2-tab FAQ × 4-5 Q each
├─ Medium dividers (color + border mix)
└─ Word count: 3000-5000

TIER 3 — DETAIL (Single Product / Single Service)
├─ Hero: 1920×600, 1 CTA
├─ 4-layer trust stack
├─ 1 centerpiece
├─ 1 entity deep
├─ 1-tab FAQ × 3-5 Q
├─ Subtle border dividers only
└─ Word count: 1000-2000

SPOKE — DEFINITIONAL (Educational / How-To)
├─ Hero: 1920×500, 0-1 CTAs (educational signal)
├─ 3-layer trust stack (brand + reviews + author bio)
├─ 1 centerpiece
├─ 1 concept deep
├─ Inline FAQ (no tabs, simple accordion)
├─ Pure typography divider (heading hierarchy only)
└─ Word count: 700-2000
```

## Cross-Page Consistency Rules

While hub and spoke differ in intensity, they must share:

### Brand consistency
- Same logo, same color palette, same typography family
- Same primary brand color for primary CTA
- Same favicon, same footer

### Component reuse
- Same button style across all tiers
- Same card structure (just different size/density)
- Same icon set
- Same form input style

### Trust signal continuity
- Same press logos used (different selection per tier OK)
- Same review platforms referenced (G2 / Trustpilot / Google)
- Same brand voice in testimonials

**Rule:** Differentiate **intensity**, NOT **brand**. User must feel "same site" across all pages.

## Application Examples

### morethanpanel.com (Reference)

| Element | Hub `/` | Spoke `/buy-instagram-followers` |
|---|---|---|
| Hero size | Full ~800px tall, video + form | Reduced ~600px, login form |
| Above-fold CTAs | 4 (Login form + Free Trial + Get Started + Sign-up) | 2 (Login form + Free Trial) |
| Trust layers | 7 full | 5 (Reviews + Press + Live stats + Verified + Newsletter — skip team) |

| FAQ tabs | 4 tabs × 4-5 Q | 6 tabs × 4-5 Q (more depth on conversion) |
| Visual dividers | Strong color blocks | Lighter, more product grids |

## Anti-Patterns

❌ **Spoke copies hub layout entirely** — visual signal not differentiated, Google can't identify tier
❌ **Hub diluted by spoke-style focus** — single CTA, minimal trust = doesn't establish authority
❌ **Trust signals identical across all pages** — duplicates not adding value
❌ **Spoke with 4+ centerpieces** — over-engineered for single-intent page
❌ **Hub with single centerpiece** — under-utilizes hub real estate
❌ **Different brand colors per tier** — confuses brand identity
❌ **FAQ duplicated verbatim** — wastes coverage, risks cannibalization
❌ **Same hero image across all pages** — generic feel, no page-specific signal

---

## Validation Checklist

For each page, verify against tier classification:

- [ ] Hero size matches tier (1920×800 hub / 700 cat / 600 detail / 500 spoke)
- [ ] CTA count matches tier (4 hub / 2 cat / 1 detail / 0-1 spoke)
- [ ] Trust layer count matches tier (7 hub / 5 cat / 4 detail / 3 spoke)
- [ ] Centerpiece count matches tier (3 hub / 1-2 cat / 1 detail / 1 spoke)
- [ ] Templated entity count matches tier (4+ hub / 5-7 sub cat / N/A detail)
- [ ] FAQ size matches tier (4 tabs hub / 2 tabs cat / 1 tab detail/spoke)
- [ ] Visual divider style matches tier (color blocks hub / mixed cat / subtle detail/spoke)
- [ ] Brand consistency maintained (logo, colors, typography, components)
- [ ] Trust signals product-specific on spoke (not generic copies)

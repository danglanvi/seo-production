# Expert Case Study Templates & Examples

## Full Template

```
[HEADLINE] - [Industry] + [Context/Differentiator]

[METADATA - optional]
Industry: [Industry]
Language: [Language]
Timeline: [Period]
Content Volume: [If notable constraint]

[RESULTS]
📊 [Primary metric]: [Before] → [After] (+X%)
📊 [Secondary metric]: [Before] → [After] (+X%)
📊 [Tertiary metric]: [Before] → [After] (+X%)
📊 [Qualitative result or notable constraint]

[DIFFERENTIATION]
What makes this [case/result] different is [unique factor].
[1-2 sentences on what WASN'T done vs what WAS done]

[METHODOLOGY]
[Named method/approach] applied:
[2-3 sentences on specific implementation]

[FRAMEWORK]
[4 principles/patterns]:
• [Principle 1]
• [Principle 2]
• [Principle 3]
• [Principle 4]

[INSIGHT]
[Header: "Why this worked" or similar]
[2-3 sentences on deeper understanding of WHY]

[CLOSING ONE-LINER]
[Memorable contrast: "This is not X. This is Y."]
```

## Element Examples (from Koray's case studies)

### Headlines

**Industry + Context:**
> "Luxury Travel SEO Case Study"
> "SaaS SEO Case Update (English Market)"

**Series + Hook:**
> "3rd Travel SEO Website in the 3rd Day, but this time with Links"

**Result-First:**
> "+255% Clicks with Only 13 Documents"

### Metadata Block

```
Industry: Luxury Travel and Tours
Language: English
```

```
Industry: SaaS
Language: English
Content Volume: Only 13 documents under a single sub-folder.
```

### Metrics Presentations

**Format A - % with absolute:**
```
📊 +185.78% clicks, 9.44K → 27K
📊 +89.97% impressions, 353K → 671K
📊 +48.15% CTR improvement, 2.7% → 4.0%
📊 Rankings influenced despite neutral BCAU impact
```

**Format B - Before → After:**
```
• Total Clicks: 24.4K → +255.63% (from 6.86K)
• Total Impressions: 11.2M → +84.48% (from 6.08M)
• Average CTR: 0.2% → +100% (from 0.1%)
• Average Position: 6.4 → ↑ 16.88% (from 7.7)
```

**Format C - Simple:**
```
• 24% increase in clicks
• 10% increase in impressions
• 51% improvement in average position
• 16% increase in CTR
```

### Differentiation Statements

> "What makes this case study different is that the growth did not come from technical SEO, server performance, or backlink changes. The impact came almost entirely from semantic and structural improvements on the pages."

> "This is a rare case where I openly discuss backlink campaigns."

> "This flips the traditional 'content first' mindset."

### Methodology Descriptions

**Named methodology:**
> "We do not build random links. We run what I call Link Sprints."

> "We deliberately used 'Function First, Content Later.'"

**Implementation detail:**
> "Instead of building links for a single site, we create a topical map and semantic content network across multiple websites, then position the main brand as the consensus source within the open web's information graph."

> "The main change was the implementation of advanced, fast filters with clear verbalizations on core tour pages. We also expanded contextual relevance by adding related destinations, locations, hotels, activities, and perspectives for different demographics."

### Framework Lists (4 Items)

**Principles:**
```
Our methodology consistently applies four principles to every important augmented query:
• Visualization
• Commercialization
• Contextualization
• Verbalization
```

**Patterns:**
```
There are four common patterns Google evaluates:
1️⃣ Function first, content later
2️⃣ Function and content together
3️⃣ Content first, function later
4️⃣ Content only, function on another page
```

**Classifications:**
```
Google differentiates between:
• Content-only websites
• Functional websites
```

### Insight Sections

**"Why this worked" header:**
> "Why this worked"
> "The key factor here is how Google classifies the website."

**Deeper explanation:**
> "If you clearly demonstrate the functional value of your product or technology, you can pass certain ranking thresholds much faster, even with minimal content."

> "Every travel product, safari, cruise, trekking, or luxury package shares the same foundational attributes through frame semantics. Performance gains come from how these attributes are expressed, structured, and distributed across visual segments."

### Closing One-Liners

**Contrast pattern:**
> "This is not content volume. This is semantic architecture."

**Amplification:**
> "Experience amplifies function."

**Technical summary:**
> "This consolidates PageRank, authority, and trust naturally around the target entity."

## Industry Variations

### Travel/Tourism
- Focus: Filters, destinations, demographics, seasonal pages
- Framework: Visualization, Contextualization
- Key metrics: CTR, impressions, position for landing pages

### SaaS
- Focus: Function vs Content, product demonstration, above-the-fold
- Framework: Center-piece annotation, functional value
- Key metrics: Clicks growth with minimal content volume

### Ecommerce
- Focus: Product semantics, category optimization, filters
- Framework: Commercialization, verbalization
- Key metrics: Revenue attribution, category rankings

### Links/Authority Building
- Focus: Link graph, semantic network across sites
- Framework: Consensus source, information graph
- Key metrics: Rankings movement, authority consolidation

## Pre-Publish Checklist

### Structure
- [ ] Results in first 5 lines
- [ ] Named methodology present
- [ ] 4-item framework list
- [ ] Closing one-liner

### Tone
- [ ] Zero personal narrative
- [ ] No hedging words
- [ ] Direct, declarative statements
- [ ] Technical vocabulary correct

### Content
- [ ] Differentiation statement clear
- [ ] "Why this worked" explained
- [ ] Specific, not generic insights
- [ ] Every sentence adds value

### Length
- [ ] 150-400 words total
- [ ] No filler/padding

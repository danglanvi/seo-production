# SOP 05 — Audit Checklist

> **Master:** [[Lexical Audit Checklist 20]] (20 checkpoints đầy đủ, feedback format GTV).
> File này thêm lớp **operational schedule** + **who does what**.

## Cadence (GTV audit schedule)

| Tần suất | Ai | Scope |
|----------|----|-------|
| Weekly | Mỗi writer self-audit | 1 bài random trong tuần |
| Bi-weekly | Content Lead | Pre-publish review mọi bài sắp ship |
| Monthly | Vincent / senior reviewer | 3-5 bài top traffic, spot pattern issues |
| Quarterly | Cả team | Full retrospective → update guideline |

## Pre-publish flow

1. Writer self-check qua [[Lexical Audit Checklist 20]].
2. Editor review + feedback format GTV.
3. Nếu verdict = REWORK → writer fix priority 3 items → re-audit.
4. Nếu PASS → ship.

## Post-publish tracking

- GSC impressions cho Representative Question — tăng sau 7-30 ngày?
- Không cannibalize page cũ? (check SERP cho target query)
- Internal links crawled? (check log crawler)

## Red flags

Xem [[10 Common Lexical Errors]] cho pattern thường gặp. Các red flag phổ biến:
- Traffic tăng nhưng impression target query flat → intent mismatch (Lỗi 7 disambiguation).
- Rank cho query sai → [[Context Sharpening]] chưa đủ.
- Orphan sau 30 ngày → internal linking chưa chạy (Layer 4 7.3, 7.8).

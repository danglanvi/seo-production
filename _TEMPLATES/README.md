| Folder | Nội dung |
|---|---|
| `account/` | Bộ mẫu Account: BBNT, email templates, SOW-KPI naming standard, tư vấn hệ thống báo cáo, dashboard demo, 2 file Excel quản lý dự án/danh mục — đọc `account/README.md` |

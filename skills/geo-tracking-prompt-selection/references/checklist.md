# BD Consultation Checklist

## Pre-Consultation Checklist

### Research Client
- [ ] Visit client website
- [ ] Identify website type: Service/Agency ☐ or E-commerce ☐
- [ ] List main products/services (top 3-5)
- [ ] Identify target market: VN ☐ US ☐ Both ☐
- [ ] Note current SEO status (if available)

### Identify Competitors
- [ ] List 5-7 potential competitors
- [ ] Check competitors' AI visibility (run 3-5 sample prompts)
- [ ] Note competitor strengths/weaknesses

### Prepare Demo
- [ ] Run 5 sample prompts relevant to client
- [ ] Screenshot AI responses showing:
  - Current brand visibility (or lack thereof)
  - Competitor visibility
  - Opportunity gaps

---

## During Consultation Checklist

### Discovery Questions

**Business Understanding:**
- [ ] What are your top 3 products/services by revenue?
- [ ] Who is your target customer?
- [ ] What's your current marketing focus?
- [ ] Are you targeting VN market, US market, or both?

**Competition:**
- [ ] Who do you consider your main competitors?
- [ ] How do you differentiate from competitors?
- [ ] Any competitors doing well in AI search?

**Goals:**
- [ ] What's your primary goal? (Brand awareness / Leads / Sales)
- [ ] Any specific products/services to prioritize?
- [ ] Timeline expectations?

### Confirm Scope
- [ ] Website type confirmed: Service ☐ E-commerce ☐
- [ ] Number of products/categories to track: ___
- [ ] Target markets confirmed: VN ☐ US ☐
- [ ] Competitors list approved: 
  1. _______________
  2. _______________
  3. _______________
  4. _______________
  5. _______________

### Set Expectations
- [ ] Explain GEO is not deterministic like SEO rankings
- [ ] Explain tracking metrics (mention rate, SOV, accuracy)
- [ ] Discuss timeline: Baseline (2 weeks) → Optimization (ongoing)
- [ ] Clarify reporting frequency: Monthly ☐ Weekly ☐

---

## Post-Consultation Checklist

### Proposal Preparation
- [ ] Summarize client requirements
- [ ] Determine prompt quantity:
  - Service/Agency: 28-40 prompts
  - E-commerce: 80-100 prompts
- [ ] List deliverables:
  - [ ] GEO Audit Report
  - [ ] Prompt Tracking List (bilingual if needed)
  - [ ] Baseline Report
  - [ ] Monthly GEO Reports

### Prompt List Draft
- [ ] Apply correct framework:
  - Service: Funnel-based (TOFU 15% / MOFU 35% / BOFU 50%)
  - E-commerce: Matrix-based (Category × Intent × Segment)
- [ ] Include bilingual prompts if targeting both markets
- [ ] Add seasonal prompts if e-commerce

### Send Proposal
- [ ] Include scope summary
- [ ] Attach sample prompt list (10-15 examples)
- [ ] Define KPIs and targets
- [ ] Specify timeline and pricing
- [ ] Schedule kick-off meeting

---

## Project Kick-off Checklist

### Finalize Prompt List
- [ ] Review prompt list with client
- [ ] Confirm products/services covered
- [ ] Confirm competitors included
- [ ] Get client approval on final list

### Setup Tracking
- [ ] Choose tracking tool/method
- [ ] Configure prompt monitoring
- [ ] Set baseline tracking date
- [ ] Schedule daily/weekly tracking

### Baseline Audit
- [ ] Run all prompts on all platforms (ChatGPT, Perplexity, Gemini, Claude)
- [ ] Record baseline metrics:
  - [ ] Mention rate: ___%
  - [ ] Share of Voice: ___%
  - [ ] Information accuracy: ___%
- [ ] Identify gaps and opportunities
- [ ] Prepare Baseline Report

---

## Monthly Review Checklist

### Data Collection
- [ ] Compile all tracking data
- [ ] Calculate metrics:
  - [ ] Mention rate change: ___% → ___%
  - [ ] SOV change: ___% → ___%
  - [ ] Accuracy: ___%

### Analysis
- [ ] Identify top performing prompts
- [ ] Identify underperforming prompts
- [ ] Note competitor changes
- [ ] Check seasonal relevance

### Optimization
- [ ] Propose prompt replacements (underperformers)
- [ ] Suggest new prompts (market changes)
- [ ] Recommend content optimizations
- [ ] Update seasonal prompts if needed

### Reporting
- [ ] Generate Monthly GEO Report
- [ ] Schedule review meeting with client
- [ ] Present findings and recommendations
- [ ] Get approval for next month's adjustments

## Red Flags During Consultation

⚠️ **Stop and clarify if client:**
- Expects guaranteed #1 rankings (explain GEO is probabilistic)
- Wants to track 200+ prompts (recommend phased approach)
- Has unrealistic timeline (<1 month for results)
- Doesn't know their competitors (help identify before proceeding)
- Only wants TOFU prompts (explain BOFU priority)

## Green Flags (Good Fit)

✅ **Ideal client characteristics:**
- Clear understanding of target audience
- Knows main competitors
- Willing to invest in content optimization
- Understands long-term nature of GEO
- Has resources to act on recommendations

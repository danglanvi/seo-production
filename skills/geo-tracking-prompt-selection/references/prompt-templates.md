## Prompt Generation Formula

```
Structure: [Product/Brand] + [Intent Action] + [Modifier]

Intent Actions by Type:
- Compare: vs, so sánh, hay, nên chọn | vs, compare, or, which
- Buy: mua ở đâu, giá, trả góp | where to buy, price, installment
- Trust: đánh giá, uy tín, review | reviews, legit, reliable
- Research: có gì mới, tính năng | what's new, features

Modifiers:
- Location: TPHCM, Hà Nội, Vietnam | HCMC, Hanoi, Vietnam
- Time: [Year], hiện tại | [Year], current
- Price: giá tốt, rẻ nhất | best price, cheapest
- Use Case: cho [Industry], cho [User Type] | for [Industry], for [User Type]
```

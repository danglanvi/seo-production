**When to use:** Designing or auditing any page where target audience has identifiable funnel position (TOFU awareness / MOFU consideration / BOFU decision-action). Visual hierarchy must reflect funnel position, not just content type.

**Core principle:** A page's visual emphasis must match the user's mindset at that funnel stage. TOFU pages emphasize Education. MOFU pages emphasize Comparison. BOFU pages emphasize Conversion. Mismatch = wrong funnel stage delivered.

---

## The Foundation Principle

Visual semantic isn't only about Google detection — it's about matching user expectation at funnel position. A user landing on:

- **TOFU page** with massive pricing tables = wrong stage (they're learning, not buying)
- **BOFU page** with long educational essays = friction (they want to act, not read)
- **MOFU page** without comparison tools = unhelpful (they need decision support)

Each funnel position has **distinct visual emphasis** that prioritizes the right element types.

## Funnel Position Visual Emphasis

### TOFU (Awareness / Education) — Visual Emphasis: Education

```
┌─────────────────────────────────────┐
│  HERO: Large explainer illustration  │
│  H1: Question or definition format   │
│  Subtitle: Foundational benefit      │
└─────────────────────────────────────┘

[Process Diagrams CENTERPIECE]
├─ Step-by-step flowcharts dominant
├─ Concept illustrations
└─ Comparison tables (categorical, NOT pricing)

[Embedded Video]
├─ "What is X?" 2-3 min explainer
└─ Founder vision OR concept teacher

[Trust signals: AUTHORITY-focused]
├─ Author credentials
├─ Research citations
└─ Industry awards

[Soft CTA below fold]
├─ "Learn More" / "Read Guide"
├─ "Subscribe for Updates"
└─ NO aggressive pricing

[Cross-link to MOFU pages]
└─ "Ready to compare options? View pricing →"
```

**Element ratios:**
- Education content: 60-70% of page real estate
- Trust/Authority signals: 20-25%
- CTAs: 10-15% (soft conversion)

### MOFU (Consideration / Comparison) — Visual Emphasis: Comparison

```
┌─────────────────────────────────────┐
│  HERO: Comparison framing           │
│  H1: "Best [X] for [Y]?" or         │
│      "Compare [X] options"          │
└─────────────────────────────────────┘

[Comparison Tables PROMINENT]
├─ Multi-tier feature matrix
├─ Side-by-side option cards
└─ Pros/cons lists

[Multi-Tier Pricing VISIBLE Above-Fold]
├─ 3-5 tier pricing cards
├─ "Best Offer" badge prominent
└─ Feature comparison per tier

[Trust Stack: 7-layer FULL]
├─ Reviews badge above-fold
├─ Multi-platform badges
├─ Verified customer reviews
└─ Live stats bar

[Side-by-Side Templated Cards]
├─ 3-4 entity options compared
└─ Each card: feature + price + CTA

[Decision-Support CTAs]
├─ "Compare All" / "Get Custom Quote"
├─ "Talk to Specialist"
└─ "Free Trial"
```

**Element ratios:**
- Comparison content: 40-50% of page
- Trust/social proof: 30-35%
- CTAs: 15-20% (medium conversion)
- Education: 5-10% (just enough context)

### BOFU (Decision / Action) — Visual Emphasis: Conversion

```
┌─────────────────────────────────────┐
│  HERO: Single-focus value prop      │
│  H1: Action-oriented "Buy [X]"      │
│  Subtitle: ROI/outcome promise      │
│  Above-fold form OR pricing card    │
└─────────────────────────────────────┘

[Live Function PROMINENT]
├─ Calculator (input → output → CTA)
├─ Live availability counter
├─ Countdown timer (cohort/promo)
└─ Real-time notification widget

[Form Above-Fold]
├─ 3-5 field qualification form
├─ Inline OR sticky
└─ Progress indicator if multi-step

[Single-Action Focus]
├─ One primary CTA
├─ Clear value-cost equation
└─ Risk reduction (guarantee, refund, trial)

[Trust signals: SOCIAL PROOF dominant]
├─ Recent purchase ticker
├─ Live stats showing scale
└─ Verified reviews specific to product

[Minimal Education]
├─ Brief L0 only (50-80 words)
├─ FAQ short (3-5 questions)
└─ Link to MOFU/TOFU for those needing more
```

**Element ratios:**
- Conversion elements: 50-60% of page
- Trust/social proof: 30-35%
- Education: 5-10% (minimum context)
- Live functions: ESSENTIAL (not optional like other tiers)

### Hybrid (Multi-Funnel) — Visual Emphasis: Layered

```
┌─────────────────────────────────────┐
│  HERO: Multi-purpose                │
│  H1: Authority + Value prop         │
│  L0 (TOFU brief)                    │
│  Inline CTA (BOFU friendly)         │
└─────────────────────────────────────┘

[ZONE 1 — TOFU layer (15-20%)]
├─ Brief education
├─ Definition L0
└─ Authority signals

[ZONE 2 — MOFU layer (40-50%)]
├─ Comparison content
├─ Multi-tier pricing
├─ Trust stack
└─ Templated entity sections

[ZONE 3 — BOFU layer (25-30%)]
├─ Live functions
├─ Conversion forms
└─ Action-focused CTAs

[ZONE 4 — Supplemental (10-15%)]
├─ FAQ encyclopedia
├─ Resource links
└─ Newsletter
```

**Element ratios depend on hybrid weighting:**
- Hybrid leaning TOFU+MOFU: 30/50/15/5
- Hybrid leaning MOFU+BOFU: 15/40/35/10
- True 3-stage hybrid: 20/45/25/10

## CTA Style by Funnel Position

### TOFU CTA Style
- Soft language: "Learn More", "Read Guide", "Subscribe"
- Outline button, less visual weight
- Small CTAs at end of sections
- Cross-link to MOFU naturally

### MOFU CTA Style
- Comparison language: "Compare Options", "Get Custom Quote", "Talk to Specialist"
- Filled button medium weight
- Multiple CTAs per page (one per option)
- Consultation-focused

### BOFU CTA Style
- Action language: "Buy Now", "Add to Cart", "Start Free Trial"
- Filled button strong weight, bold colors
- Single primary CTA dominant
- Risk reduction nearby ("30-day refund", "no credit card needed")

### Hybrid CTA Style
- Layered CTA hierarchy:
  - Primary: Action-oriented (BOFU style)
  - Secondary: Comparison-oriented (MOFU style)
  - Tertiary: Education-oriented (TOFU style)
- 2-4 CTAs total above-fold

## Word Density by Funnel Position

| Position | Word density | Reasoning |
|---|---|---|
| TOFU | 5000-10000 words | Education needs depth |
| MOFU | 2000-4000 words | Decision support, not over-education |
| BOFU | 1000-2000 words | Friction reduction, action focus |
| Hybrid | 4000-7000 words | Multi-purpose needs varied density |

## Visual Pacing Considerations

### TOFU Pacing
- Slow rhythm (long sections of content)
- Frequent section breaks with strong visuals
- Sub-headings every 200-300 words
- Encourage deep reading

### MOFU Pacing
- Medium rhythm
- Comparison tables interspersed
- Section breaks every 400-500 words
- Encourage scanning + comparison

### BOFU Pacing
- Fast rhythm
- Above-fold conversion-ready
- Minimal text between CTAs
- Encourage immediate action

### Hybrid Pacing
- Variable rhythm
- Stages clearly demarcated visually
- Bridge sections between funnel layers
- Allow user to self-select stage

## Application Examples

### morethanpanel.com (Hybrid — MOFU+BOFU dominant)

**Funnel position:** Hybrid leaning MOFU+BOFU
**Visual emphasis:** 15% education + 45% comparison + 30% conversion + 10% supplement

| Element | Implementation |
|---|---|
| TOFU layer | "How does SMM Panel Work?" 5-step + 12 advantages list |
| MOFU layer | Multi-tier pricing per platform + comparison badges |
| BOFU layer | Calculator + Inline login form + Live notification ticker |
| Supplement | FAQ multi-tab encyclopedia |

**Verdict:** Correctly weighted for B2C+B2B reseller vertical where users mix learning + buying.

### APOHAIR Homepage (Hybrid — MOFU+BOFU + light TOFU)

**Funnel position:** Hybrid B2B (MOFU dominant + BOFU heavy)
**Recommended visual emphasis:** 10% education + 50% comparison + 30% conversion + 10% supplement

| Funnel layer | Recommended elements |
|---|---|
| Light TOFU | Hero L0 definition (50-80 words) + brief "How OEM works" |
| MOFU dominant | Factory-vs-Supplier comparison + Product line templated + Testimonials |
| BOFU heavy | Above-fold WhatsApp + qualification form + Live capacity counter |
| Supplement | FAQ 4-tab encyclopedia |

**Anti-pattern to avoid:** Treating Apohair homepage as pure BOFU (forces conversion before trust built) OR as pure TOFU (over-educates B2B buyer who already knows what hair extensions are).

### TAG Course Landing (BOFU heavy with TOFU layer)

**Funnel position:** BOFU + TOFU education layer
**Visual emphasis:** 25% education + 25% comparison + 40% conversion + 10% supplement

| Funnel layer | Recommended elements |
|---|---|
| TOFU | "What is Claude A-Z?" intro + outcome promise |
| MOFU | 3 pricing tiers (Self-paced / Mentorship / Cohort) comparison |
| BOFU dominant | Cohort countdown + spots remaining + Enroll CTA + qualification form |
| Supplement | FAQ on prerequisites + curriculum |

### GTV Service Page (MOFU dominant)

**Funnel position:** MOFU pure (B2B service consideration)
**Visual emphasis:** 15% education + 55% comparison + 20% conversion + 10% supplement

| Funnel layer | Recommended elements |
|---|---|
| TOFU light | "Why Semantic SEO" brief intro |
| MOFU dominant | Methodology comparison + Case studies + Service tier comparison |
| BOFU light | "Book Free Audit" CTA + qualification form |
| Supplement | FAQ on methodology + ROI calculator |

## Funnel Position Audit

For any existing page, audit:

### Step 1: Identify intended funnel position
- TOFU only / MOFU only / BOFU only / Hybrid (which layers)?

### Step 2: Map current visual elements
- List all visual elements present
- Categorize each by which funnel position it serves

### Step 3: Compute element ratio
- What % of real estate is TOFU elements?
- What % is MOFU?
- What % is BOFU?

### Step 4: Compare to ideal ratio
- Match between intended position and actual visual ratio?
- Mismatch indicates wrong page emphasis

### Step 5: Recalibrate if needed
- Add/remove elements to align with intended funnel position

## Anti-Patterns

❌ **TOFU page with massive pricing tables** — wrong stage delivered
❌ **BOFU page with 5000-word essay** — friction at decision stage
❌ **MOFU page with single-tier pricing only** — fails comparison support
❌ **Hybrid page with single funnel layer** — misses multi-purpose intent
❌ **Pure TOFU CTA "Buy Now"** — too aggressive for awareness stage
❌ **BOFU page without live function** — misses urgency/availability signal
❌ **TOFU page without authority signals** — lacks credibility for education
❌ **Same CTA style across all funnel positions** — doesn't match user mindset

---

## Validation Checklist

For each page, verify funnel position alignment:

- [ ] Intended funnel position identified (TOFU/MOFU/BOFU/Hybrid)
- [ ] Hero matches funnel position (illustration/comparison/action)
- [ ] CTA style matches funnel position (soft/comparison/action)
- [ ] Element ratios match expected for funnel position
- [ ] Word density matches expected for funnel position
- [ ] Visual pacing matches funnel position
- [ ] Trust signals appropriate for funnel position
- [ ] Live functions present where required (BOFU/Hybrid)
- [ ] Pricing tables present where required (MOFU/BOFU)
- [ ] Education elements present where required (TOFU/Hybrid)
